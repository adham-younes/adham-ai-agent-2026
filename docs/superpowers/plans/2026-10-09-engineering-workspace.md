# Engineering workspace implementation plan

Goal: deliver the approved project/task workstation with real sandbox execution and durable evidence.
Architecture: an owner-scoped PostgreSQL project ledger binds one Eve session per project; shared execution services back HTTP and agent tools. Real sandbox operations record workspace revisions, immutable attempts, files, and checks. Evergreen components compose the workstation.
Tech stack: existing Next 16, React 19, Eve 0.53, Mastra, pg/Supabase; Evergreen Radix and Phosphor. Preserve runtime/model and existing dependency versions.
Spec: ../specs/2026-10-09-engineering-workspace-design.md (approved by user: نفذ).
Global constraints: no existing data deletion; trusted principal ownership; fail closed on storage failure; no verified task from prose or draft reports; bounded payloads; legacy sessions retained.
Review focus: ownership, revision-bound checks, replay/concurrency, actual sandbox evidence, component fidelity/accessibility.

Implementation ruling: installed Eve 0.53 dispatches built-in and declared subagent tools through its runtime registry; executing their public descriptor directly throws, static tool-name wrappers collide, and public hooks observe already durable events. Avoid private framework patches. Preserve the security intent through authenticated originating task plus immutable parent-call/root-session evidence, and one exclusive project lease per delegated operation. Reject children whose pinned task differs from the active task. This retains serial writes and prevents stale-child authority without inventing a parent attempt that Eve does not expose.
